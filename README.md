# Inventory Management System

A comprehensive C# application for managing inventory operations, tracking stock levels, and organizing product information.

## Features

- Inventory tracking and management
- Stock level monitoring
- Product management
- Data organization and reporting

## Technologies

- **Language**: C#
- **.NET Framework**: Built with modern .NET

## Getting Started

### Prerequisites

- .NET SDK or .NET Framework installed
- Visual Studio or another C# IDE

### Installation

1. Clone the repository:
```bash
git clone https://github.com/liewvk/InventoryManagementSystem.git
```

2. Navigate to the project directory:
```bash
cd InventoryManagementSystem
```

3. Build the project:
```bash
dotnet build
```

4. Run the application:
```bash
dotnet run
```
